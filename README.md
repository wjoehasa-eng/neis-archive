# 📚 Y공작소 이슈 아카이브 (껍데기 PWA)

2026년 1~10월 **Y공작소 네이버 카페** 본문 **1,026건**·댓글 **8,622건**을 **교사 실무 플레이북**으로 다시 정리한 앱입니다.
주제별 글 목록이 아니라, **월별 업무 흐름 → 이달의 지뢰 → 경중별 1줄 결론** 순서로 읽힙니다.

- 라이브: <https://wjoehasa-eng.github.io/neis-archive/>
- **이 저장소에는 데이터가 한 줄도 없습니다.** 게시글·댓글·개인정보·드라이브 파일 ID 를 담지 않습니다.
  실제 데이터는 소유자의 **비공개 구글 드라이브**에 있는 JSON 파일 하나이고, 앱은 그 파일을
  [Apps Script](apps-script/Code.gs) 다리를 통해 **나 권한으로** 받아 이 기기(IndexedDB)에만 담아 둡니다.

## 쓰는 법

1. 처음 한 번: [처음 설정하기](apps-script/SETUP.md) (4단계)
2. 이후: 앱을 열면 저장해 둔 데이터가 바로 뜨고, 30분이 지났으면 조용히 최신을 확인합니다.
3. **동기화** 버튼으로 직접 새로 받을 수 있고, **⚙ 설정 → JSON 파일 열기**로 내려받은 파일을 열 수도 있습니다.

## 화면

| 부분 | 내용 |
| --- | --- |
| 월 스트립 | 맨 위 고정. **전체**(한 해 흐름) 또는 1~10월 중 하나를 고릅니다. 숫자는 **대표 카드 수**로 통일했고, 원문 글·댓글 수는 달을 고른 뒤 헤더 부제목과 툴팁에 보입니다. |
| 검색·필터 바 | 월 스트립 바로 아래에 **상시 고정**. 바로 아래에 검색창과 `전체 / 🔴 사고주의 / 🟡 예외주의 / 🟢 단순팁 / 담임 / 부장·관리자 / 맑은샘 답변` 칩이 붙어 있어 1초 안에 찾습니다. 모바일에는 `업무흐름｜지뢰｜카드` 점프 버튼과 카드 수·상태가 함께 표시됩니다. |

| 필터 | 경중 · 담임 / 부장·관리자 · 맑은샘 답변 · 주제. 각 칩에 장수가 표시됩니다. |
| 검색 | 표준 제목·원문 제목·본문·정리문·메뉴 경로·댓글 전체(1,026건) 검색. 카드를 먼저, 댓글 많은 순으로 보여 줍니다. |
| 월별 원문 글 | 그 달 원문 글 전체 목록. 펼치면 원문 제목·정리·본문·댓글 전문, 카드면 결론도 함께. |
| 주제별 정리 | 주제 22개의 리드 문장·핵심 포인트·**⚠️ 의견 갈림**. "이 주제 카드만 보기"로 좁힐 수 있습니다. |
| 오프라인 | 서비스 워커가 껍데기를, IndexedDB가 데이터를 담아 두어 비행기 모드에서도 열립니다. |

카드의 **메뉴 경로와 `공식` 표시는 2026학년도 경기도 초등학교용 나이스(NEIS) 교무업무 매뉴얼에서 확인된 것만** 넣었습니다(매뉴얼 쪽수 표기). 확인되지 않은 경로는 넣지 않습니다.

## 구조

```
index.html            화면 뼈대 (데이터 없음)
styles.css            디자인
app.js                데이터 받기·캐시·검색·필터·렌더링
manifest.json         PWA 매니페스트
sw.js                 서비스 워커 (껍데기만 캐시)
icons/                앱 아이콘 192 · 512 · maskable
apps-script/Code.gs   비공개 드라이브 JSON 전달용 Apps Script
apps-script/SETUP.md  처음 설정 4단계
```

### 데이터 흐름

```
비공개 구글 드라이브 (neis-y2026-archive.json, 공유 없음)
        │  Apps Script 웹앱 (실행: 나 / 액세스: 모든 사용자, 선택적 ACCESS_KEY)
        ▼
app.js  ──POST text/plain──▶  JSON 약 3.2MB
        │
        ├─ IndexedDB(neis-archive/archive)에 저장 → 다음 실행은 즉시 표시
        └─ 화면 렌더링
```

- 연결 주소는 `localStorage` 에만 저장되고 코드·저장소에는 들어가지 않습니다.
- 데이터 파일은 읽기 전용으로만 쓰이며, 앱에서 드라이브로 쓰기·공유를 하지 않습니다.
- 껍데기만 GitHub Pages에 공개되므로, 주소를 아는 사람도 연결 주소(과 키) 없이는 데이터를 볼 수 없습니다.

## 개발 메모

- 빌드 도구 없음. 파일을 고치고 `sw.js` 의 `VERSION` 을 올리면 다음 방문에 반영됩니다.
- 로컬 확인: 아무 정적 서버로 이 폴더를 열고, **⚙ 설정 → JSON 파일 열기**로 실제 JSON을 넣어 봅니다.
- 화면의 숫자·주제·카드·흐름·지뢰는 모두 JSON에서 옵니다. 코드에는 콘텐츠가 없습니다.
- 예전 양식(`schema: 1`) 데이터를 열면 "이 달의 플레이북이 없습니다 — 동기화하세요" 안내가 뜹니다.
