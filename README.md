# 📚 Y공작소 이슈 아카이브 (껍데기 PWA)

2025년 1~12월과 2026년 1~10월 **Y공작소 네이버 카페** 본문 **2,948건**·댓글 **23,397건**을 **교사 실무 플레이북**으로 다시 정리한 앱입니다.
주제별 글 목록이 아니라, **월별 업무 흐름 → 이달의 지뢰 → 경중별 1줄 결론** 순서로 읽히고,
달마다 **[종합(25+26) | 2026년 | 2025년]** 으로 그 해 자료만 골라 볼 수 있습니다.
2025년은 달마다 100건씩 고르게 뽑던 방식을 버리고 **카페 실제 게시량에 따른 경중**으로 다시 뽑았습니다(2·3·12월 집중, 1,922건). 카드 수도 그 밀도를 따릅니다 — 3월 43장, 2월 30장, 12월 23장.

- 라이브: <https://wjoehasa-eng.github.io/neis-archive/>
- **이 저장소에는 데이터가 한 줄도 없습니다.** 게시글·댓글·개인정보·드라이브 파일 ID 를 담지 않습니다.
  실제 데이터는 소유자의 **비공개 구글 드라이브**에 있는 JSON 파일 하나이고, 앱은 그 파일을
  [Apps Script](apps-script/Code.gs) 다리를 통해 **나 권한으로** 받아 이 기기(IndexedDB)에만 담아 둡니다.

## 쓰는 법

1. 처음 한 번: [처음 설정하기](apps-script/SETUP.md) (4단계)
2. 이후: 앱을 열면 저장해 둔 데이터가 바로 뜨고, 30분이 지났으면 조용히 최신을 확인합니다.
3. **동기화** 버튼으로 직접 새로 받을 수 있고, **⚙ 설정 → JSON 파일 열기**로 내려받은 파일을 열 수도 있습니다.

카드의 **메뉴 경로와 `공식` 표시는 2026학년도 경기도 초등학교용 나이스(NEIS) 교무업무 매뉴얼에서 확인된 것만** 넣었습니다(매뉴얼 쪽수 표기). 확인되지 않은 경로는 넣지 않습니다.

## 구조

```
index.html            화면 뼈대 (데이터 없음)
styles.css            디자인
app.js                데이터 받기·캐시·검색·필터·렌더링
manifest.json         PWA 매니페스트
sw.js                 서비스 워커 (껍데기만 캐시)
icons/                앱 아이콘 192 · 512 · maskable
apps-script/Code.gs   비공개 드라이브 JSON 전달용 Apps Script
apps-script/SETUP.md  처음 설정 4단계
```

### 데이터 흐름

```
비공개 구글 드라이브 (`neis-y2026-archive.json` — 이름은 그대로, 내용은 2025+2026 통합 · 공유 없음)
        │  Apps Script 웹앱 (실행: 나 / 액세스: 모든 사용자, 선택적 ACCESS_KEY)
        ▼
app.js  ──POST text/plain──▶  JSON 약 6.3MB
        │
        ├─ IndexedDB(neis-archive/archive)에 저장 → 다음 실행은 즉시 표시
        └─ 화면 렌더링
```

- 연결 주소는 `localStorage` 에만 저장되고 코드·저장소에는 들어가지 않습니다.
- 데이터 파일은 읽기 전용으로만 쓰이며, 앱에서 드라이브로 쓰기·공유를 하지 않습니다.
- 껍데기만 GitHub Pages에 공개되므로, 주소를 아는 사람도 연결 주소(과 키) 없이는 데이터를 볼 수 없습니다.

## 데이터 JSON 형식

빌드 산출물 `neis-y2025-2026-archive.json` (앱이 읽는 단일 파일, schema 3 — 드라이브에는 같은 파일 ID에 덮어씀)

```jsonc
{
  "app": "neis-y-archive", "schema": 3,
  "title": "…", "built_at": "…", "years": [2026, 2025],
  "source": { "articles": 2948, "comments": 23397, "cards": 382, "topics": 22,
              "by_year": { "2025": {…}, "2026": {…} } },
  "months": ["01", …, "12"], "monthStat": { "2025-03": { "a": 311, "c": 3333, "k": 18 }, … },
  "topics":   [ { "n": "권한·메뉴·자료권한", "c": "#2563eb", "lead": "…", "points": ["…"],
                  "warn": "…", "faq": [0, …], "y": { "2025": 96, "2026": 124 },
                  "k": { "2025": 12, "2026": 22 } } ],
  "cards":    { "0": { "s": 3, "sv": "critical", "r": "admin", "g": "common", "y": 2025,
                       "t": "[업무영역] 상황·조치", "ot": "원문 제목", "ch": "칩", "one": "1줄 결론",
                       "ex": "예외", "mp": "메뉴 경로", "mpp": 246, "mn": "공식 근거" } },
  "monthlyPlaybooks": { "2025-12": { "year": 2025, "label": "…", "summary": "…",
                            "steps": [["단계 이름", "할 일 1줄", [0, …]], …],
                            "pitfalls": [["지뢰 제목", "설명", [0, …]], …] } },
  "articles": [ { "i": 0, "d": "2025-12-18 09:46", "m": "2025-12", "b": "게시판", "t": "…",
                  "w": "…", "u": "…", "n": 4, "l": 1, "p": "주제", "x": "", "s": 0, "pa": 1,
                  "bd": "본문", "bc": { "n": "닉네임", "d": "2025-12-19", "c": "…", "ms": 1 },
                  "cm": [ { "n": "닉네임", "d": "2025-12-19", "c": "댓글", "r": 0 } ] } ]

```

`cards.s` 는 정렬용 가중치(3 사고주의 / 2 예외주의 / 1 단순팁), `cards.y` 는 출처 연도입니다.
`monthStat`·`monthlyPlaybooks` 의 키는 `YYYY-MM` 이고, `months` 는 달 번호(`01`~`12`)입니다. 예시의 번호는 형식을 보여 주기 위한 자리표시자입니다.

## 개발 메모

- 빌드 도구 없음. 파일을 고치고 `sw.js` 의 `VERSION` 을 올리면 다음 방문에 반영됩니다.
- 로컬 확인: 아무 정적 서버로 이 폴더를 열고, **⚙ 설정 → JSON 파일 열기**로 실제 JSON을 넣어 봅니다.
- 화면의 숫자·주제·카드·흐름·지뢰는 모두 JSON에서 옵니다. 코드에는 콘텐츠가 없습니다.
- 예전 양식(`schema: 1`)이나 한 해짜리(`schema: 2`) 데이터를 열어도 달·연도 전환은 되지만, 없는 달은 "플레이북이 없습니다" 안내가 뜹니다.
