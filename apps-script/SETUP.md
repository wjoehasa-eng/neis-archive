# 처음 설정하기 (4단계 · 5분)

앱은 **껍데기**입니다. 데이터는 내 구글 드라이브의 비공개 JSON 파일에만 있고, 아래 순서로 그 파일을 읽을 다리를 한 번 놓으면 끝입니다.

## 1. 새 Apps Script 만들기
<https://script.new> 를 열어 새 프로젝트를 만듭니다. (구글 로그인은 데이터가 있는 그 계정으로)

## 2. 코드 붙여넣기
이 폴더의 **`Code.gs`** 내용을 전부 복사해 편집기의 내용을 지우고 붙여넣은 뒤 **저장**(💾)합니다.

- 위쪽 `FILE_NAME` 이 드라이브 파일 이름과 같은지 확인하세요. (기본값 `neis-y2026-archive.json`)
- 보안을 더하려면 `ACCESS_KEY = ''` 안에 긴 문장을 넣고, 앱 설정의 **접근 키**에 같은 값을 넣습니다. (비워도 동작)

## 3. 웹앱으로 배포
**배포 → 새 배포 → 유형: 웹앱**

| 항목 | 값 |
| --- | --- |
| 설명 | Y공작소 아카이브 |
| 다음 사용자로 실행 | **나** |
| 액세스 권한 | **모든 사용자** |

**배포**를 누르면 구글 계정 승인 화면이 한 번 뜹니다 → 계정 선택 → *고급* → *이동(안전하지 않음)* → 허용.
마지막에 나오는 **웹앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 액세스를 **모든 사용자**로 두는 이유: 앱(GitHub Pages)은 내 구글 로그인 쿠키를 실어 보낼 수 없습니다.
> 대신 이 주소는 50자 넘는 임의 문자열이고, 파일 자체는 **공유되지 않은 채** 스크립트가 나 권한으로 읽습니다.
> 주소를 남에게 알려 주지 마세요. 필요하면 2단계의 `ACCESS_KEY` 로 한 겹 더 잠급니다.

## 4. 앱에 주소 넣기
앱(<https://wjoehasa-eng.github.io/neis-archive/>)에서 **⚙ 설정** → **비공개 연결 주소**에 붙여넣고 **저장하고 동기화**.

- 상태 표시가 `불러옴 … · 드라이브` 로 바뀌고 본문·댓글 수가 나오면 성공입니다.
- 한 번 받아 두면 다음부터는 앱을 열 때 자동으로 최신을 확인합니다. (30분에 한 번, 조용히)

---

## 데이터를 새로 올릴 때
1. 같은 이름(`neis-y2026-archive.json`)으로 드라이브 파일을 **교체**합니다. (이름이 같으면 스크립트가 가장 최근 파일을 읽습니다)
2. 앱에서 **동기화**를 누르거나, 앱을 다시 열면 새 데이터로 바뀝니다.

## 잘 안 될 때
| 증상 | 확인 |
| --- | --- |
| `연결 주소 응답 401/403` | 배포 액세스가 **모든 사용자**인지 |
| `응답을 읽지 못했어요` | 주소가 `…/exec` 인지 (`/dev` 는 로그인 쿠키가 필요해 앱에서 안 됩니다) |
| `드라이브에 … 파일이 없습니다` | 파일 이름·계정 확인, 휴지통에 있지 않은지 |
| `접근 키가 맞지 않습니다` | `Code.gs` 의 `ACCESS_KEY` 와 앱의 접근 키가 같은지 |
| 코드를 고쳤는데 그대로 | **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포 |
